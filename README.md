# Танчики.io — VK Mini App

Игра в стиле agar.io: вы танк, едите точки, уничтожаете других, растёте и эволюционируете (ур. 5, 10, 15, 20).

## Запуск на GitHub Pages
1. Загрузите ВСЕ файлы из архива в корень репозитория (index.html, style.css, game.js).
2. Settings → Pages → Branch: main, папка / (root).
3. Адрес вида https://ник.github.io/репозиторий/ вставьте в dev.vk.com → ваше приложение → «URL приложения».
4. В game.js замените `groupId:1` на id вашего сообщества.
5. В настройках VK-приложения включите нужные методы Bridge (подписка, приглашение, стена, избранное, уведомления).

Награды и баланс — объект `CFG` в начале game.js. Вне ВК игра работает в демо-режиме.
